# Specs

Working documents, not code. Two kinds live here:

- `*.plan.md` — test plans from `/plan-tests`, consumed by `/generate-tests`.
- `*.design.md` — framework design proposals from `/architect`, executed by `/refactor`.

Both are point-in-time records: they describe the app and the codebase as they were when written,
so treat their file paths and findings as history rather than as current truth.
